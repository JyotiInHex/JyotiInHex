## About

I'm a developer and UI/UX designer based in **Assam, India**. I work across the product-building process — from shaping an interface and defining its interactions to implementing the frontend and connecting the underlying systems.

I care about interfaces that feel clear, responsive and considered, and codebases that remain practical to maintain.

- **Design:** UI/UX, interface systems, interaction design and prototyping.
- **Frontend:** Building responsive web experiences and interactive interfaces.
- **Backend:** Working with application logic, APIs and databases.
- **Exploration:** Creative coding, browser capabilities, animation and 3D on the web.
